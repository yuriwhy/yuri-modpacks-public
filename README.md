### Highly recommended launchers:
- [Prism Launcher](https://prismlauncher.org/) or [PineconeMC (aka ElyPrismLauncher)](https://elyprismlauncher.github.io/download/)
- [Modrinth App](https://modrinth.com/app)

*(If you use another launcher not listed here, it should work fine as long as it supports importing .mrpack files)*

### Why don't my modpacks support the CurseForge app?
- Although Prism Launcher offers an option to export as a CurseForge modpack (.zip), numerous bugs often occur, frequently resulting in an "incomplete" export; this is certainly an issue with Prism Launcher's export function that has not yet been fixed.
- I am looking for a way to export modpacks for the CurseForge app without issues, even if it requires using a different launcher or tool.
